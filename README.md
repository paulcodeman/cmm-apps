# C-- Applications for KolibriOS

Исходники приложений KolibriOS на C--: браузер, файловые и графические инструменты,
настройки системы, примеры и общая библиотека. Это отдельная коллекция приложений,
а не исходный код компилятора [SPHINX C--](https://github.com/paulcodeman/cmm).

## Структура

- `browser/`, `eolite/`, `iconedit/`, `appearance/` и другие каталоги — приложения.
- [lib/](lib/) — общие заголовки и вспомогательные модули.
- [examples/](examples/), [template/](template/), [kex_main/](kex_main/) — примеры и заготовки.
- `Tupfile.lua` внутри каталогов — входы, выходы и defines конкретного приложения.
- [build.sh](build.sh) — массовая сборка целей из Tupfile; результаты собираются в `dist/`.

## Сборка

Нужны отдельно установленный C--, его конфигурация и POSIX-утилиты; для Windows
используйте подходящий Bash/MSYS2. При установленном компиляторе:

```sh
CMM=/absolute/path/to/c-- ./build.sh LANG_ENG
```

Скрипт также принимает `LANG_RUS` и другие defines, но полнота переводов зависит от
приложений. Он пересоздаёт `dist/` и собирает промежуточные `.com` в каталогах
программ. Для одной программы повторяйте команду и defines из её `Tupfile.lua`.
Пути, имена `.c`, ресурсов и целевых бинарников сохранены для совместимости правил сборки.

## Статус

Совместимость зависит от версии C-- и библиотек KolibriOS. Успех компиляции не
подтверждает правильность интерфейса, выражений или системных вызовов во время
исполнения. В рамках оформления компиляторы и полученные бинарники не запускались.
Исходные уведомления и авторство сохранены.
